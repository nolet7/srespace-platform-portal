Thank you for installing {{ .Values.global.appName }}.

Application namespace:

  {{ .Values.global.namespace }}

Frontend service:

  {{ .Values.frontend.name }}

API service:

  {{ .Values.api.name }}

PostgreSQL service:

  {{ .Values.postgres.name }}

Ingress host:

  {{ .Values.ingress.host }}

To check application pods:

  kubectl get pods -n {{ .Values.global.namespace }} | grep {{ .Values.global.appName }}

To check services:

  kubectl get svc -n {{ .Values.global.namespace }} | grep {{ .Values.global.appName }}

To check ingress:

  kubectl get ingress -n {{ .Values.global.namespace }}

To test the API health endpoint:

  curl -s -H "Host: {{ .Values.ingress.host }}" http://localhost:8081/api/health

To test categories:

  curl -s -H "Host: {{ .Values.ingress.host }}" http://localhost:8081/api/categories

To test products:

  curl -s -H "Host: {{ .Values.ingress.host }}" http://localhost:8081/api/products

To view API logs:

  kubectl logs -n {{ .Values.global.namespace }} deploy/{{ .Values.api.name }} --tail=100

To view frontend logs:

  kubectl logs -n {{ .Values.global.namespace }} deploy/{{ .Values.frontend.name }} --tail=100

To restart the API:

  kubectl rollout restart deploy/{{ .Values.api.name }} -n {{ .Values.global.namespace }}

To restart the frontend:

  kubectl rollout restart deploy/{{ .Values.frontend.name }} -n {{ .Values.global.namespace }}

To uninstall:

  helm uninstall {{ .Values.global.appName }} -n {{ .Values.global.namespace }}
