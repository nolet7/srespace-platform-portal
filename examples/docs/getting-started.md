# Getting Started

Use this portal to manage platform engineering services and documentation.

## Basic Workflow

1. Sign in with GitHub.
2. Open the Catalog.
3. Register a component using a `catalog-info.yaml` file.
4. Add documentation using TechDocs.
5. Connect Kubernetes metadata using Backstage annotations.
6. Use templates to standardize new services.

## Local URLs
