# SRESpace Platform Portal

Welcome to the SRESpace Platform Portal.

This Backstage portal is designed for SRE and Platform Engineering workflows, including service catalog management, GitHub integration, Kubernetes visibility, TechDocs, API discovery, and software templates.

## Main Capabilities

- GitHub authentication
- Software catalog
- Register existing components
- TechDocs documentation
- Kubernetes plugin
- API catalog
- Catalog graph
- Software templates
- Platform engineering onboarding
